# PROJECT_CONSTITUTION.md

## Purpose
Defines the non-negotiable operating rules for this project.

## Core Principles
- repo docs are memory, not chat history
- bounded work beats broad autonomy
- architecture is a first-class artifact
- shortcuts must be visible
- done includes docs, tests, and operational thinking
- ask humans only for high-leverage decisions
- parallel work requires contract discipline

## Required Artifacts
- `CLAUDE.md`
- `architecture.md`
- `roadmap.md`
- `status.md`
- relevant module docs
- relevant ADRs

## Prohibited Behaviors
- silent architecture drift
- undocumented breaking changes
- untracked “v2 later” promises
- relying on chat memory instead of repo docs
