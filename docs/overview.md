# Overview

AI Engineering Playbook is a reusable document-and-prompt system for managing AI-assisted software development beyond toy projects.

It focuses on:
- preserving context across sessions
- making architecture explicit
- reducing drift in large codebases
- bounding agent work
- making roadmap and design changes safer
- keeping humans in the loop only where their decisions matter most

This repo is intentionally tool-agnostic. It can be used with Claude Code, Codex, or similar code agents.
