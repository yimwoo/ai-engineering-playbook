# Daily Use and Continuous Improvement

This repository is not only a public playbook.
It can also serve as a personal daily operating repo for AI-assisted software engineering.

## Two modes
### 1. Reusable playbook mode
Used for templates, starter kits, prompts, and guidance others can adopt.

### 2. Personal operating mode
Used for:
- lessons learned
- prompt improvements
- failure patterns
- retrospectives
- experiments with new workflows
- tool-specific notes kept separate from the generic system

## Important rule
Keep the generic operating model stable.
Put experiments and personal notes in clearly separated folders so the core playbook stays clean and reusable.
