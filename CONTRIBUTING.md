# CONTRIBUTING.md

Thank you for contributing to AI Engineering Playbook.

## Contribution Types
- improve templates
- improve prompts
- add examples
- refine documentation
- add adoption guidance for real-world repos

## Principles
- prefer practical guidance over vague advice
- keep templates actionable and adaptable
- avoid unnecessary process overhead
- document tradeoffs explicitly
- optimize for reuse across different project types

## Contribution Flow
1. explain the problem or improvement clearly
2. keep changes scoped and reviewable
3. update related docs if behavior or guidance changes
4. include rationale for opinionated changes

## Pull Request Guidance
A good PR should explain:
- what changed
- why it changed
- who benefits
- whether it affects existing templates or prompts
