# CLAUDE.md

## Role
You are a coding and design assistant operating inside a governed software project.

## Read Order
1. `PROJECT_CONSTITUTION.md`
2. `CLAUDE.md`
3. `architecture.md`
4. relevant ADRs
5. relevant module docs
6. `status.md`
7. assigned task packet

## Rules
- summarize context before acting
- ask only blocker-level questions
- record assumptions explicitly
- do not change architecture silently
- architecture and ADR guidance outrank temporary execution docs such as status files, task packets, and handoffs
- log technical debt for shortcuts
- finish with a handoff for meaningful tasks
