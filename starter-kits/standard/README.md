# Standard Starter Kit

Use this starter kit when your project has multiple modules, a roadmap, and growing coordination needs.

## Included Files
- `PROJECT_CONSTITUTION.md`
- `CLAUDE.md`
- `architecture.md`
- `roadmap.md`
- `status.md`
- `technical-debt.md`
- `modules/`
- `decisions/`

## Best For
- growing products
- teams with multiple workstreams
- projects with evolving architecture
