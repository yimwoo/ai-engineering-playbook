# Lightweight Starter Kit

Use this starter kit when you want the smallest useful document set for a new or early-stage project.

## Included Files
- `PROJECT_CONSTITUTION.md`
- `CLAUDE.md`
- `architecture.md`
- `status.md`

## Best For
- solo builders
- MVPs
- small codebases
- fast-moving early projects

## How to Use
1. copy these files into your project repo
2. fill in high-level architecture and current status
3. ask the agent to use them as source-of-truth docs
4. add more structure later only when needed
