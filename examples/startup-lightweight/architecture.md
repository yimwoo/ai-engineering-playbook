# architecture.md

## System Overview
A lightweight web application with a single backend service and a simple frontend.

## Architectural Style
Modular monolith.

## Major Areas
- auth
- user settings
- core domain logic
- web UI
- persistence

## Current Constraints
- small team
- fast iteration
- avoid premature complexity

## Known Gaps
- observability is basic
- roadmap is informal
- some module boundaries may evolve
