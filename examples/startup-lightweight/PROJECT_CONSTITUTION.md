# PROJECT_CONSTITUTION.md

## Purpose
Defines the basic operating rules for this project.

## Core Principles
- repo docs are memory, not chat history
- bounded work beats broad autonomy
- shortcuts must be visible
- humans decide high-leverage tradeoffs
- architecture and status should stay current enough to guide the next session

## Required Artifacts
- `CLAUDE.md`
- `architecture.md`
- `status.md`

## Prohibited Behaviors
- silent architecture drift
- undocumented breaking changes
- relying only on chat history for project memory
