# roadmap.md

## Delivery Strategy
Milestone-driven delivery with bounded execution units and explicit design checkpoints.

## Milestones
### Milestone 1: Foundation
- repo setup
- governance docs
- CI baseline
- auth skeleton
- module scaffolding

### Milestone 2: Core Domain
- main business workflows
- core data model
- initial reporting views

### Milestone 3: Hardening
- observability improvements
- risk reduction
- performance tuning
- operational readiness

## Deferred Items
- non-critical future extensions
- optional optimization layers
