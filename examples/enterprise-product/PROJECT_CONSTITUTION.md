# PROJECT_CONSTITUTION.md

## Purpose
Defines the non-negotiable operating rules for this enterprise-style project.

## Core Principles
- repo docs are memory, not chat history
- architecture is a first-class artifact
- bounded work beats broad autonomy
- shortcuts must be visible and tracked
- done includes docs, tests, and operational thinking
- humans should decide high-leverage tradeoffs
- parallel work requires contract discipline

## Required Artifacts
- `PROJECT_CONSTITUTION.md`
- `CLAUDE.md`
- `AGENTS.md`
- `architecture.md`
- `roadmap.md`
- `status.md`
- `technical-debt.md`
- relevant module specs
- ADRs
- task packets
- handoffs

## Prohibited Behaviors
- silent architecture drift
- undocumented breaking contract changes
- undocumented schema changes
- untracked "v2 later" promises
- treating partial work as complete
