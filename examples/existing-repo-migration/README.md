# Existing Repo Migration Example

This example shows how to adopt the playbook incrementally in an existing codebase.

## Suggested sequence
1. run a repo audit
2. preserve useful existing docs
3. classify docs into keep, fix, merge, archive, or superseded
4. create `PROJECT_CONSTITUTION.md`
5. create `CLAUDE.md`
6. create `status.md`
7. add missing governance and architecture artifacts incrementally

## Example starter files in this folder
- `PROJECT_CONSTITUTION.md`
- `CLAUDE.md`
- `status.md`
- `alignment-plan.md`
