# Existing Repo Migration Example

This example shows how to adopt the playbook incrementally in an existing codebase.

## Suggested sequence
1. create `PROJECT_CONSTITUTION.md`
2. create `CLAUDE.md`
3. create `status.md`
4. run a repo audit
5. preserve useful existing docs
6. add missing governance and architecture artifacts incrementally

## Example starter files in this folder
- `PROJECT_CONSTITUTION.md`
- `CLAUDE.md`
- `status.md`
- `alignment-plan.md`
