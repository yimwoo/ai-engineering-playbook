# Common Failure Modes

## Purpose
Track recurring failure patterns across code agents.

## Examples
- agent asks too many clarifying questions one by one
- agent silently changes architecture
- agent optimizes for a shortcut without logging debt
- agent loses track of prior decisions
- agent scopes work too broadly
- agent finishes code without updating docs

## For each failure mode
- what triggers it
- how to detect it early
- how to prevent it
- how to recover when it happens
